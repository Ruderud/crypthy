## v0.2.0 ✅ 코인 허브 + PC 관리 + 채굴량·수익 (Windows)

- **코인 허브**: 큐레이션 카탈로그(`catalog/catalog.json`)를 바탕으로 코인 → 알고리즘 → 호환 채굴 툴 추천 순위와 공식 저장소 링크를 보여 준다. 앱이 채굴기를 내려받거나 실행하지 않는다.
- **PC 관리**: nvidia-smi 대시보드, 안전 감시(위험 시 알려진 채굴기 정지만 하고 재시작하지 않음), 전력 제한(UAC 1회 예약 작업), 트레이, 로컬 읽기 전용 상태 API, 자동 업데이트를 제공한다.
- **채굴량·수익**: 채굴기 통계 API 어댑터(SRBMiner)와 풀 공개 API(Kryptex)로 채굴량을 읽고, 원화 환산·전기료 차감, 채굴 vs 대여 비교를 보여 준다.

## v0.3.0 ✅ Ubuntu(Linux) 지원 (실기 미검증)

배경: Vast.ai 호스팅은 네이티브 Ubuntu만 지원한다(WSL·Docker Desktop 불가). 나중에 Ubuntu 듀얼부팅으로 "대여 + 유휴 채굴"을 할 때도 같은 허브를 쓰기 위한 단계다. v0.3.0은 Linux에서 허브가 동작하는 데까지만 다룬다.

**범위**
- 플랫폼 계층
  - nvidia-smi 수집은 공통으로 쓴다.
  - Windows 전용 경로와 명령(tasklist, taskkill, PowerShell, System32 경로)은 플랫폼별 구현으로 분리한다.
- GPU 벤더 감지: Linux는 `/sys/class/drm/*/device/vendor`를 쓴다.
- 프로세스 감지·안전 정지
  - Linux는 `/proc` 기반으로 감지한다. 플랫폼별 실행 파일 이름은 카탈로그에서 확인된 것만 대상으로 한다.
  - **Vast 고객 컨테이너(docker/containerd 하위) 프로세스는 절대 정지하지 않는다.** cgroup과 조상 프로세스로 판별하고, 테스트로 보장한다.
- 전력 제한(root 필요): 설치 시 `pkexec` 1회로 다음을 만든다.
  - systemd oneshot 서비스: 부팅 시 적용
  - polkit 규칙: 해당 사용자가 그 서비스 하나만 시작할 수 있게 허용
  - Windows와 같은 보안 원칙을 따른다. 실행 스크립트는 root 소유이고, 사용자가 쓸 수 있는 파일은 데이터로만 읽으며 bus id·W 범위를 검증한다.
- 자동 실행과 트레이
  - 자동 실행: `~/.config/autostart/crypthy.desktop`
  - 트레이: Ubuntu AppIndicator
- 패키징·배포
  - AppImage: electron-updater 자동 업데이트 지원
  - deb: 자동 업데이트 없음
  - CI: ubuntu-latest 빌드 잡을 추가하고, Release에 AppImage, `latest-linux.yml`, deb, 통합 `SHA256SUMS.txt`를 올린다.
- 테스트: 플랫폼 분기 단위 테스트. CI는 ubuntu·windows 매트릭스로 돌린다.

**완료 기준**
- CI 매트릭스가 통과한다.
- Release에 Windows·Linux 산출물이 모두 올라간다.
- 실제 Ubuntu 기기 테스트는 **미검증**으로 명시한다.

## v0.4.0 ✅ 헤드리스 호스트 + 원격 화면 (실기 미검증)

배경: Vast.ai 호스트로 쓸 Ubuntu Server(GUI 없음)에서 Crypthy 를 서비스로 돌리고, 다른 PC 의 Crypthy 가 Tailscale 사설망으로 붙어 같은 화면을 본다.

- 코어 분리: 상태·폴링·안전 정지·수익을 `core.ts` 로 옮기고, `main.ts`(Electron 셸)와 `headless.ts`(Node)가 같은 코어를 쓴다.
- 원격 API: 기본 127.0.0.1·읽기 전용, 특정 IP 하나에만 바인딩(0.0.0.0 불가), 읽기/쓰기 토큰 분리(0600), Host 헤더 검사, 지갑 원문 비노출. 켜기 동의·위험 정지 확인은 409 로 클라이언트에 되묻는다.
- 클라이언트: 설정 → 원격 호스트 연결. 토큰은 메인 프로세스만 갖고 safeStorage 로 암호화 저장.
- Linux 배포: `crypthy-headless-<버전>.tar.gz`(Node 18+), `install.sh`(sudo) → `/opt/crypthy-headless`, `/var/lib/crypthy-headless`, systemd 시스템 유닛(일반 사용자 권한), 전력 제한은 같은 sudo 로 설치. 자동 업데이트 없음.
- CI: Ubuntu 에 실제 설치(systemd, Node 18) 후 API 확인.
- 미검증: 실제 Ubuntu Server·Tailscale·Vast 호스트 환경.

## v0.5.0 ✅ SafeTrade 자동 매도·현금화 경로 메모

- SafeTrade 공식 API(서명 헤더)로 매일 정한 시각에 지정가 매도. 시장가 없음, 하한가 = max(최저가, 기준가 × (1 − X%)) 아래로는 팔지 않음, 비정상 호가면 그날 건너뜀, 하루·1건 한도, PRL 마켓만.
- 키는 사용자가 직접 입력: 데스크톱 safeStorage, 헤드리스 0600 파일 또는 systemd LoadCredential. 화면·원격·로그·상태 API 로 내보내지 않음.
- 하루 1회·한 기기: 첫 주문 전 날짜 기록, 공유 장부 폴더의 날짜별(UTC) 기록, 중간에 꺼지면 다음 시작 때 주문 취소·기록.
- 원격 화면은 켜기·모의 실행·시각만. 출금·지갑 송금은 자동화하지 않고 알림만.
- 실거래 미검증: 모의 실행부터 시작.

## 다음 후보: Vast 호스트 연동

이번 단계는 계획만 세운다. 실제 구현은 Ubuntu 호스트가 준비된 뒤 시작한다.

**범위(안)**
- Vast 호스트 상태 표시: 임대 여부, 임대 수익, reliability, 머신 상태
  - Vast 호스트 API 또는 CLI를 쓰며, 읽기 전용이다.
  - 호스트 API 키는 OS 키체인에만 저장한다. 평문 설정 파일과 로그에는 남기지 않는다.
- 유휴 채굴 전환 안내: Vast `defjob`(대여 없을 때 돌릴 기본 작업)으로 채굴 컨테이너를 설정하는 방법을 안내하고 상태를 보여 준다.
  - 앱이 직접 Vast 설정을 바꾸지는 않는다.
- 안전 감시와 함께 쓰기
  - 대여 중에는 고객 워크로드를 절대 정지하지 않는다(v0.3.0 예외 규칙 재사용).
  - 대여 중에는 알림만 보낸다.
- 비교 패널: 실제 임대 수익과 채굴 수익을 비교한다. 지금 쓰는 시장 중앙값 대신 실측값을 쓴다.
- 로그인이 필요한 정보(내 호스트 매물, 임대 수익, reliability)는 Vast 공식 API 키로 읽는다.
  - 브라우저 로그인 쿠키를 저장하는 방식은 쓰지 않는다.
  - API 키는 사용자가 Vast 콘솔에서 직접 발급해 입력한다.
  - 키는 Electron `safeStorage`로 암호화해 저장한다(Windows DPAPI, Linux libsecret). 헤드리스 호스트는 0600 파일 또는 systemd `LoadCredential`을 쓴다. 평문 설정 파일에는 저장하지 않는다.
  - 로그, 로컬 상태 API, 리포트, 알림 문구에는 절대 노출하지 않는다. 마스킹도 하지 않고 아예 넣지 않는다.
  - 설정에서 키 삭제 버튼을 제공한다. 삭제하면 저장소에서 즉시 지운다.
  - 시장 시세(공개 검색)는 지금처럼 로그인 없이 읽는다. v0.3.3에서 verified 필터, 하위 25%, 표본 수 표시가 추가되었다.

**선행 조건**
- RUD의 Ubuntu 듀얼부팅과 Vast 호스트 등록. 사용자가 결정한다.
- Vast 호스트 API의 공식 문서 확인: 엔드포인트, 인증, 사용 약관.

## 아이디어 📝: 쓰는 중인 GPU 는 채굴 쉬기

- v0.4.4 의 GPU 별 채굴 선택 위에, 사용자가 그 GPU 를 쓰는 동안(게임·작업: 채굴기 외 프로세스의 GPU 사용, 전체 화면 앱, 입력 활동 등)은 자동으로 채굴에서 빼고, 일정 시간 쓰지 않으면 다시 넣는다.
- 판단 기준·지연 시간·화면 출력 GPU 처리는 실측 후 정한다. 안전 원칙(위험 정지 뒤 자동 재시작 없음)은 그대로.

## 공통 원칙

- 채굴기를 앱이 내려받거나 설치하지 않는다. 사용자가 구성한 채굴기만, 사용자가 누를 때만 켜고 끈다. 위험 정지 뒤에는 다시 켜지 않는다.
- 지갑 시드·비밀번호·토큰을 요구하거나 저장하지 않는다. 공개 주소만 쓴다.
- 보안 설정(Defender·방화벽 등)을 바꾸지 않는다.
- 기능 단위로 커밋하고, main에는 일반 push만 한다(force 금지). CI가 통과한 뒤 태그를 단다.
- 확인하지 못한 값은 "미확인"으로 표시하고 출처를 남긴다.
