처음 설정 Crypthy 는 채굴기를 설치하지 않습니다. 채굴기는 직접 설치·구성하고, 여기서는 감시·수익 확인과 켜기·끄기를 합니다

  2.

    실행 중인 채굴기의 해시레이트·share 를 읽습니다. SRBMiner-MULTI 는 --api-enable --api-port 21550 옵션으로 실행하세요. 포트는 아래 설정에서 바꿀 수 있습니다.

    일별 순익 (막대, 왼쪽 · 흐린 막대 = 추정) · 누적 PnL (선, 오른쪽)
    
      
    
      
    
        
    
          소급 적용
          
          
    
            
            
            
          
    
        
    
        
    
          매도 기록 (선택 — 실현 손익 계산용, 로컬에만 저장)
          
    
            
            
            
            
            
            
          
    
        
    
      
    
    
    

    
    
      
    SafeTrade 자동 매도 하루 1회 · 지정가만 · 하한가 아래로는 팔지 않음 · 출금·지갑 송금은 하지 않음
        
        
      
    
      
    
      
    
      
    
      
    
        
        
        
        
        
        
        
        
        
        
        
        
        
        
    
      
    
      
    하한가 = max(최저가, 기준가 × (1 − 최대 하락%)). 기준가는 SafeTrade 24시간 평균가와 CoinGecko 시세 중 높은 값입니다. 가장 낮은 매도 호가보다 한 틱 아래에 지정가로 걸고, 안 팔리면 정한 시간마다 조금씩 내리되 하한가 아래로는 내리지 않습니다. 호가가 비정상(스프레드가 넓음, 매수 깊이가 얕음, API 오류)이면 그날은 팔지 않고 알립니다. 판 기록은 PnL 에 "실현 매도"로 남습니다.
    
      
    
        SafeTrade API 키 
        
    
          
          
          
        
    
        
    SafeTrade 에서 키를 만들 때 거래(Trade) 권한만 주고 출금 권한은 주지 마세요. 가능하면 이 PC 의 IP 로 제한하세요. SafeTrade API 로는 키의 권한을 확인할 수 없으므로 Crypthy 가 대신 막아 주지 못합니다.
    
        
    키는 이 PC 의 OS 보안 저장소로 암호화해 저장하고, 화면·원격 화면·로그·상태 API 로 내보내지 않습니다. 헤드리스(Ubuntu)는 install.sh --safetrade-key 파일 (root 0600, systemd LoadCredential) 로 넣습니다.
