      코인·채굴기 목록 
      
          
      
          
      
          
      Crypthy 는 채굴기를 내려받거나 설치하지 않습니다. 저장소 링크를 열어 직접 확인·설치하세요. dev fee 는 각 출처에서 확인한 값이며, 확인하지 못한 값은 "미확인"으로 표시합니다. 채굴기 바이너리는 보안 프로그램에 탐지될 수 있으니 출처와 해시를 직접 확인하세요. 코인은 "수익 계산"에서 고릅니다.
      
        
      
      
      
    
      
    
      
      
      
      
      
    
      
        

  
  
    
      처음 설정 Crypthy 는 채굴기를 설치하지 않습니다. 채굴기는 직접 설치·구성하고, 여기서는 감시·수익 확인과 켜기·끄기를 합니다
      
    
        
      
      1. 지갑·풀 
        
        
          
          
        
        
        
        
        
        풀 공개 통계(잔액·지급)를 조회하는 데만 씁니다. 공개 주소만 입력하고, 시드 문구·비밀번호·토큰은 절대 넣지 마세요.
        
      
        2. 
      
      2. 채굴기 통계 API 
        
        실행 중인 채굴기의 해시레이트·share 를 읽습니다. SRBMiner-MULTI 는 --api-enable --api-port 21550 옵션으로 실행하세요. 포트는 설정 › 채굴기에서 바꿀 수 있습니다.
        
      
        3. 
      
      3. 켜기·끄기 방식 (선택) 
        
        앱과 트레이에서 채굴을 켜고 끄려면 설정 › 채굴기에서 방식(예약 작업·systemd 유닛·실행 파일)을 고르세요.
        
        
      
        4. 
    
      
    
      
        

  
    
      자동 매도 설정 
      
    
      
      
      
      
      
      
      
      
        고급 — 하한가·호가·한도·값 내림
        
      
          
          
          
          
          
          
          
          
        
      
      
      
      
      하한가 = max(최저가, 기준가 × (1 − 최대 하락%)). 기준가는 SafeTrade 24시간 평균가와 CoinGecko 시세 중 높은 값입니다. 가장 낮은 매도 호가보다 한 틱 아래에 지정가로 걸고, 안 팔리면 정한 시간마다 조금씩 내리되 하한가 아래로는 내리지 않습니다. 호가가 비정상이면 그날은 팔지 않고 알립니다.
      
    
      
    
      
        

  
    
      SafeTrade API 키 
      
    
      
      
      
      
      SafeTrade 에서 키를 만들 때 거래(Trade) 권한만 주고 출금 권한은 주지 마세요. 가능하면 이 PC 의 IP 로 제한하세요. SafeTrade API 로는 키의 권한을 확인할 수 없으므로 Crypthy 가 대신 막아 주지 못합니다.
      
      
      키는 이 PC 의 OS 보안 저장소로 암호화해 저장하고, 화면·원격 화면·로그·상태 API 로 내보내지 않습니다. 저장한 값은 다시 보여 주지 않습니다. 헤드리스(Ubuntu)는 install.sh --safetrade-key 파일 (root 0600, systemd LoadCredential) 로 넣습니다.
