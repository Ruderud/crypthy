처음 설정 모든 항목이 끝나야 채굴을 시작할 수 있습니다

  1. SRBMiner-MULTI
    -

    이 앱은 채굴기를 포함하거나 내려받지 않습니다. 공식 GitHub(doktor83/SRBMiner-Multi)에서 직접 설치한 뒤 폴더를 지정하세요. Windows 보안이 채굴기를 차단하면 예외 설정은 사용자가 직접 판단해서 하세요(앱은 보안 설정을 바꾸지 않습니다).

  2. 지갑·풀

    공개 주소만 입력합니다. 시드 문구·비밀번호·토큰은 절대 넣지 마세요. 기본 지갑은 없으며 앱 수수료(dev fee)도 없습니다.

  3. GPU 매핑

    SRBMiner의 GPU id는 nvidia-smi 번호와 다를 수 있습니다(예: 내장 GPU가 0번). "매핑 감지"는 모든 GPU로 SRBMiner를 10~40초 실행한 뒤 PCI bus로 짝을 맞추고 정지합니다. 아래 GPU 설정 표에서 직접 입력해도 됩니다.

  4. 위험·비용 고지 동의
    • 채굴은 전기 요금이 들고, GPU 발열·팬·커넥터 수명에 부담을 줍니다. 수익은 코인 시세·난이도에 따라 손실이 될 수 있습니다.
    • 채굴 수익은 입력한 지갑으로만 지급됩니다. 앱은 수수료를 떼지 않고 외부로 데이터를 보내지 않습니다(공개 시세·풀 조회 제외).
    • 안전 감시는 보조 수단입니다. 하드웨어 상태는 사용자가 직접 확인해야 합니다.
